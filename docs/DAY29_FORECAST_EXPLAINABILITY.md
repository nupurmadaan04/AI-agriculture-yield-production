## 2. Feature Attribution & XAI Boundaries

### For Machine Learning Strategies (Oilseeds, Sugarcane)
- Feature importance is extracted directly from the certified model artifacts (`model_metadata.json`).
- Native tree split attribution measures the Gini reduction across decision trees for all pre-season lag features:
  - `yield_lag_1`: Previous-year yield ($t-1$)
  - `yield_lag_2`: Two-year prior yield ($t-2$)
  - `yield_rolling_3yr_mean`: 3-year rolling average historical yield
  - `area_lag_1`: Cultivated area reported in previous season
  - `state_encoded`: Categorical state spatial identifier
  - `year`: Temporal trend index

### Strict XAI Labeling Rule
- Feature importance is labeled as **Native Tree Split Feature Importance**.
- The existing XAI subsystem uses **Marginal Reference Perturbation Attribution**.
- It is **never** labeled as SHAP, TreeSHAP, or SHAP values unless explicitly generated by Shapley value algorithms.

### For Statistical Baseline Strategies
- Feature-level ML attribution is explicitly marked as **`NOT_APPLICABLE`**.
- The system explains: *"Feature-level ML attribution is not applicable because this forecast uses a historical statistical strategy (Historical District Mean / Persistence). Predictions are derived from longitudinal empirical observations."*

## 3. Empirical Uncertainty vs Confidence Intervals

### Empirical Ensemble Spread ($P10$–$P90$)
- For tree ensemble models (such as Oilseeds Random Forest), the uncertainty spread is derived empirically from the predictions of individual constituent trees in the ensemble ($P10 = 747.07$, $P90 = 1544.69$, Spread = $797.62\text{ kg/ha}$).
- This spread is displayed as:
  $$\text{Empirical } P10\text{--}P90 \text{ ensemble range: } \pm 398.81\text{ kg/ha}$$

### Non-Gaussian Disclaimer
- Every uncertainty display includes the mandatory scientific notice:
  > *"This range represents an empirical ensemble spread and is not a formal confidence interval."*
- Prohibited terminology:
  - ❌ "90% confidence interval"
  - ❌ "90% probability"
  - ❌ "guaranteed forecast range"
  - ❌ "prediction certainty"

### Baseline Strategies
- Statistical baselines return `NOT_AVAILABLE` for empirical ensemble spread to prevent manufacturing fake uncertainty.
