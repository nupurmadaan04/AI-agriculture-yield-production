# Day 32: Evidence Traceability & Semantic Taxonomy

## 1. Semantic Evidence Taxonomy

Every numeric metric and analytical display in the Day 32 Decision Workspace is bound to an explicit semantic category. The system strictly separates historical truth, empirical metrics, statistical predictions, and hypothetical simulations.

| Semantic Category | Meaning | Workspace Examples | Verification Rule |
| :--- | :--- | :--- | :--- |
| `OBSERVED` | Direct historical physical measurement from canonical dataset | Past district yield ($\text{kg/ha}$), past crop production | Must originate directly from `agricultural_panel.csv` with $\text{Year} < \text{forecast\_year}$. |
| `DERIVED` / `HISTORICAL_REFERENCE` | Statistical summary calculated across historical records | Historical 10-year mean, standard deviation, linear trend slope | Deterministic math over observed data; no model inference. |
| `PREDICTED` | Authoritative pre-season point estimate from certified forecast strategy | Governed baseline forecast | Generated by `PredictionService` using certified model artifacts. |
| `SCENARIO` | What-if simulation under synthetic or policy input perturbations | Conservative / Moderate / Stress scenario yields | Output of `ScenarioService`; explicit disclaimer of non-prediction. |
| `MODEL_ATTRIBUTION` | Feature importance or local attribution | Tree SHAP values ($\Delta \text{kg/ha}$ per feature) | Statistical association only; non-causal interpretation. |
| `VALIDATION` | Out-of-time historical performance benchmark | 4-fold walk-forward MAE (2014–2017), Win Rate % | Extracted from `StrategyRegistry` and `CertificationGuard`. |
| `MONITORING` | Operational health and runtime stability telemetry | Feature / prediction PSI drift scores, active alerts | Live metrics from `ForecastMonitoringService`. |
| `PROVENANCE` | Auditability and cryptographic verification metadata | SHA-256 fingerprint, model hash, dataset hash, request ID | Generated at inference time; immutable record. |

## 2. Cryptographic Provenance Fingerprinting

To guarantee reproducibility and full auditability, every baseline forecast generated in the workspace computes a deterministic cryptographic hash:

$$\text{Fingerprint} = \text{SHA-256}\left(\text{crop} \,\|\, \text{state} \,\|\, \text{district} \,\|\, \text{forecast\_year} \,\|\, \text{predicted\_yield} \,\|\, \text{strategy\_id}\right)$$

### Exposed Provenance Fields:
- **`request_id`**: Unique operational trace ID (`ws-<uuid>`).
- **`prediction_fingerprint`**: 64-character hexadecimal SHA-256 hash.
- **`model_identifier`**: Certified model filename (e.g. `oilseeds_rf_production.pkl` or `Sugarcane_GradientBoosting_v1.pkl`).
- **`dataset_identifier`**: Canonical agricultural panel hash (`sha256:d8c6b5e4f3a...`).
- **`strategy_identifier`**: Certified strategy key (`oilseeds`, `sugarcane`, `rice`, `wheat`).
- **`audit_reference`**: Timestamped entry reference registered in prediction audit trail.

## 3. Temporal Boundary Isolation

Temporal integrity is enforced through strict isolation rules:

1. **Information Horizon**:
   For any forecast targeted at year $T$, the historical context panel only admits observations where:
   $$\text{Observation Year} < T$$
   No contemporaneous or future harvest statistics may enter the baseline prediction features or the historical reference panel.

2. **Unharvested Future Years**:
   When evaluating future or uncompleted crop years (e.g. 2026), post-harvest error evaluation is strictly marked:
   `evaluation_status = "EVALUATION_UNAVAILABLE"`
   `evaluation_note = "Forecast year 2026 is unharvested or pending final crop cutting survey compilation; observed outcome not yet realized."`
   The system never fabricates future ground truth.

3. **Past Ground Truth**:
   For historical years where verified crop-cutting survey data exists in the panel (e.g. 2017), the workspace displays:
   - Observed Actual Yield
   - Governed Forecast Yield
   - Out-of-Time Prediction Error ($\text{Predicted} - \text{Observed}$)
