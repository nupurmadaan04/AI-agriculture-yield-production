# DAY 35 — Scientific Terminology & Semantic Dictionary Audit

## 1. Overview

Day 35 conducted a comprehensive audit of all user-facing strings, headers, metrics, and documentation to ensure strict adherence to scientifically defensible language. High-risk marketing exaggerations and ambiguous terms have been completely replaced with exact statistical and agronomic terminology.

---

## 2. Forbidden vs. Approved Terminology

| High-Risk / Disallowed Term | Approved Scientific Terminology | Rationale |
|---|---|---|
| ❌ "100% accurate" / "perfect prediction" | ✅ "Governed empirical forecast" / "Bounded estimate" | Agricultural yields exhibit irreducible climate and soil stochasticity. |
| ❌ "Guaranteed yield" | ✅ "Projected baseline yield" | Future agricultural outcomes are never guaranteed. |
| ❌ "95% Confidence Interval" | ✅ "Empirical P10–P90 Ensemble Interval" | The interval reflects random forest decision tree dispersion, not a frequentist sampling distribution. |
| ❌ "AI decides" / "AI chooses" | ✅ "Governed strategy selection based on walk-forward validation" | Algorithm selection follows deterministic tournament rules and validation thresholds. |
| ❌ "Real-time IoT/Sensor Monitoring" | ✅ "Operational Surveillance & Signal Monitoring" | The data panel reflects historical district-level aggregates without live field IoT feeds. |
| ❌ "Optimal Scenario" / "Best Policy" | ✅ "Simulated Scenario Delta" / "What-If Projection" | The platform does not apply subjective utility functions; decision ranking is reserved for human leaders. |
| ❌ "Causal attribution" | ✅ "Marginal Reference Perturbation Attribution" | Feature importance denotes mathematical sensitivity within the trained model space, not biological cause-and-effect. |
| ❌ "Day 30/31/32 Governance" | ✅ "Governance Layer" / "Production Strategy" | Internal project development timeline labels must never be visible to external users. |

## 3. Standard Semantic Labeling Convention

To prevent cognitive ambiguity between observed historical facts, model projections, and hypothetical what-ifs, the platform applies standardized textual tags across all screens:

```
[OBSERVED]             Historical factual observations recorded in the canonical panel.
[PREDICTED]            Out-of-sample pre-season yield forecast generated by a certified strategy.
[SCENARIO]             Hypothetical simulation generated under modified input assumptions.
[DERIVED]              Deterministic mathematical calculations (e.g., Yield = Production / Area).
[VALIDATION]           Historical out-of-sample walk-forward test metrics (MAE, RMSE, R²).
[MONITORING]           Covariate drift tracking (PSI), error decomposition, and bias diagnostics.
[MODEL_ATTRIBUTION]    Empirical feature sensitivity metrics (Marginal Reference Perturbation).
[PROVENANCE]           Cryptographic SHA-256 digital hashes, request IDs, and execution audit trails.
```

All labels are implemented with both textual badges and high-contrast color tokens, ensuring full accessibility for color-blind users.
