This scientific audit establishes the authoritative, canonical standards for data splits, metric definitions, uncertainty terminology, prediction labeling, audit log characterizations, and causal language across the entire AI Agriculture Decision Intelligence Platform.

## 3. Canonical Rice Legacy Model Metrics

For all references to the foundational single-crop Rice Random Forest model evaluated on the 2013–2017 test holdout, the canonical metrics are:

- **Coefficient of Determination ($R^2$)**: **`0.7866`**
- **Mean Absolute Error (MAE)**: **`353.01 kg/ha`**
- **Root Mean Squared Error (RMSE)**: **`513.11 kg/ha`**
- **Mean Absolute Percentage Error (MAPE)**: **`18.04%`**

*Audit Rule*: These metrics apply strictly to the Rice legacy model and must not be confused with the multi-crop walk-forward MAE (which is computed across 14 crops on expanding 2014–2017 origins).

## 4. Uncertainty & Prediction Spread Terminology

### Audit Directive
The platform's uncertainty bands ($P_{10} - P_{90}$) are derived from empirical tree quantile ensembles and residual quantiles.
- **Allowed Terminology**: **"Empirical P10–P90 ensemble interval coverage (81.3%)"** or **"Empirical quantile prediction spread"**.
- **Prohibited Terminology**: *"81.3% confidence interval"*, *"statistical confidence"*, or *"formal conformal prediction interval"*.

---

## 5. Prediction Example Labeling

All single-district numerical outputs generated by the inference engine (e.g. `Oilseeds → Ludhiana → 817.06 kg/ha`, `Sugarcane → Meerut → 9,469.76 kg/ha`) must be labeled as:
- **`Illustrative prediction example`** or **`Operational inference example`**.
- They must **never** be presented as aggregate validation performance metrics.

---

## 6. Audit Trail Terminology

Because the audit logger appends records to a CSV file backed by in-memory cryptographic SHA-256 fingerprinting:
- **Canonical Terminology**: **"Append-oriented prediction audit log with cryptographic provenance"**.
- **Prohibited Terminology**: *"Immutable blockchain audit trail"*, unless dedicated hardware immutability or ledger chaining is explicitly integrated.

## 7. Causal Language Sanitization

All references across documentation, backend schemas, and UI strings have been audited to eliminate ungrounded causal claims:

| Context | Prohibited Causal Phrasing | Approved Observational Phrasing |
| :--- | :--- | :--- |
| Weather & Climate | *"Rainfall causes higher crop yield."* | *"Rainfall features were associated with yield variation in the analyzed historical data."* |
| Exogenous Features | *"Adding rainfall features improves prediction accuracy."* | *"Adding the evaluated exogenous rainfall features did not demonstrate consistent error reduction during temporal walk-forward validation."* |
| Feature Importance | *"Cultivated area drives production yield."* | *"Cultivated area exhibited high relative Gini importance in the Random Forest feature attribution profile."* |
| Policy & Scenarios | *"Allocating nitrogen fertilizer will increase output by 12%."* | *"Under the simulated scenario assumptions, the model estimates a 12% higher yield relative to baseline historical averages."* |
